# 전체 프로젝트 남은 작업

기준일: 2026-10-20 (`c51166a` 기준). 이전 판(2026-10-19)을 `tests/test_cases.md`, `docs/A_ROLE.md`, `docs/B_ROLE.md`, `docs/B_PRESENTATION.md`, 현재 코드와 다시 대조했다. 이번 정리에서는 AWS 조회·배포·브라우저 테스트를 새로 실행하지 않았다.

상태: **미구현**(코드·산출물 없음), **보완**(기존 구현에 추가 작업), **확인 필요**(구현은 있으나 완료 증거 부족), **문서 정리**(완료됐으나 문서 표시가 어긋남), **선택**(필수 아님).

담당 열은 오케스트레이터가 일을 나눌 때 쓰는 기준이다([`CLAUDE.md`](../CLAUDE.md) 참고). **사람**은 실물 휴대폰·크롬 확장 조작·AWS 자격 증명·발표 리허설처럼 에이전트가 직접 할 수 없는 일이다. 에이전트는 그 절차·스크립트·기록 양식을 준비하고 결과를 문서에 반영한다.
